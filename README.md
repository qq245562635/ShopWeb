# ShopWeb

卖虚拟物品和卡券的单页小商店。纯静态（HTML + CSS + JS），不用构建、不用服务器，放到 GitHub Pages 就能访问，手机和微信内置浏览器都能用。

## 功能

- 每个商品是一张礼品卡样式的卡面（9 种配色可选，也可以换成自己的图）；卡券类分类显示成带撕口的券
- 商品按分类展示，支持搜索；首屏展示三张扇形展开的推荐卡
- 商品可以有多个规格（面值、月卡/年卡等）、划线价、库存，库存为 0 自动显示「售罄」
- 购物车（保存在买家浏览器里）、立即购买
- 下单：填联系方式和备注 → 生成订单号 → 展示收款码 → 一键复制订单信息发给客服
- 买家可以在「订单」里找回在这台设备上下过的单
- 首屏按北京时间显示「客服在线 / 休息中」
- 每个商品都能复制独立链接（`#item=商品id`），方便发到群里

## 要改的地方

所有内容都在 `assets/js/` 下的两个文件里，改完刷新页面即可：

| 文件 | 内容 |
| --- | --- |
| `config.js` | 店名、介绍、公告、客服时间、分类、收款码、联系方式、购买须知 |
| `products.js` | 商品列表（文件开头有每个字段的说明） |

**收款码**：把你的微信 / 支付宝收款码图片放进 `assets/img/`，然后在 `config.js` 的 `payments` 里改成对应文件名，例如 `qr: "assets/img/wechat.png"`。只用一种收款方式就删掉另一项。

**卡面**：每个商品用 `theme` 选配色（violet、coral、teal、midnight、gold、rose、forest、ocean、graphite），`icon` 选图标。想用自己的图当卡面，把图片放进 `assets/img/`，在商品里加 `image: "assets/img/xxx.jpg"`（建议 16:10）。首屏推荐的三张卡在 `config.js` 的 `featured` 里改。

**自动发卡**：如果某个商品已经在发卡平台上架，可以给它加 `link: "https://..."`，按钮会直接跳转过去购买，不走本站下单。

**界面颜色**：`assets/css/style.css` 开头的 `:root` 里集中了页面颜色和字体。

## 部署到 GitHub Pages

1. 打开仓库 Settings → Pages
2. Source 选 **Deploy from a branch**，Branch 选 `main`、目录 `/ (root)`，保存
3. 等一两分钟，访问 `https://<你的用户名>.github.io/ShopWeb/`

本地预览：在仓库目录运行 `python3 -m http.server`，打开 http://localhost:8000 。

## 需要知道的限制

这是纯静态页面，没有后台：

- **不能自动确认收款**。买家扫码付款后，需要你在微信 / 支付宝里核对金额和备注里的订单号，再手动发货。
- **订单不会传到你这里**，只保存在买家自己的浏览器里，所以下单页会引导买家「复制订单信息」发给客服。
- 库存是写死在 `products.js` 里的数字，卖掉后要自己改。

以后想做自动收款、自动发卡，需要接一个支付接口和后端（或者直接用发卡平台，配合上面的 `link` 字段）。
